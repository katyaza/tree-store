# TreeStore

Тестовое задание на реализацию древовидного хранилища данных и его визуализацию в таблице.

## Стек

- Vue 3
- TypeScript
- Vite
- AG Grid
- Vitest

## Установка

```bash
npm install
```

## Запуск проекта
```bash
npm run dev
```

## Сборка проекта
```bash
npm run build
```

## Запуск тестов
```bash
npm run test
```

## Что реализовано
TreeStore

Класс TreeStore реализует работу с древовидной структурой:

getAll() — получение всех элементов;
getItem(id) — получение элемента по id;
getChildren(id) — получение непосредственных дочерних элементов;
getAllChildren(id) — получение всех дочерних элементов любого уровня вложенности;
getAllParents(id) — получение цепочки родителей от элемента до корня;
addItem(item) — добавление элемента;
removeItem(id) — удаление элемента вместе со всеми потомками;
updateItem(item) — обновление элемента с корректным изменением родительской связи.

Для повышения производительности используются Map и Set, что позволяет быстро получать элементы и связи между родителями и детьми.

## Тесты

Для TreeStore написаны unit-тесты, проверяющие:

получение всех элементов;
поиск элемента по id;
получение дочерних элементов;
получение всех потомков;
получение цепочки родителей;
добавление элементов;
удаление элементов вместе с потомками;
обновление элементов;
изменение родителя элемента.

## Требования

Проект содержит package.json и package-lock.json и может быть установлен и запущен стандартными командами npm.

Основная логика хранения дерева отделена от Vue-компонентов, поэтому TreeStore может независимо импортироваться и тестироваться.
